Abandonment rate

Abandonment rate (%) = abandoned paddy area (ha) ÷ total paddy area (ha) × 100.

This calculation is shown only where the abandoned-grid value can be matched to a paddy-grid feature and the denominator is greater than zero. The code uses a point-in-polygon match between grid cells; confirm the two layers share the same grid coverage and CRS.

Limitations

  • DSD-level or grid-level estimates do not identify the exact boundaries of every abandoned field.
  • Community reports are not automatically verified evidence of illegal activity.
  • Administrative filters depend on the actual attribute names and values in the supplied GeoJSON files.
  • Large GeoJSON files can make GitHub Pages slow. Simplify geometries or export only required fields where appropriate.
